# Menu Background Setup

## To add your dungeon background image:

1. Save your dungeon corridor image as: `menu-background.jpg`
2. Place it in the root folder: `d:\dungeon knights robinhood\`
3. The CSS is already configured to use it!

## File should be named exactly:
```
menu-background.jpg
```

## Current theme colors (matching the green dungeon aesthetic):
- Green glowing lights (from torches in your image)
- Dark stone panels with transparency
- Atmospheric green glow effects
- Gold accents for UI elements

The image will show through with a dark overlay to keep text readable!
