## 🚀 Quick Deploy Steps

### 1. Copy Contract to Remix
- Open https://remix.ethereum.org/
- Create file: `DungeonKnightsGameV3_1.sol`
- Copy from: `contracts/DungeonKnightsGameV3.1-RewardsOnly.sol`

### 2. Compile
- Compiler: 0.8.20+
- Enable optimization: 200 runs

### 3. Deploy
**Network:** Robinhood Testnet (46630)

**Constructor:**
```
_knightNFT: 0x06c7D4b0C35858c78c3B213fbf50fB4A25f20512
_dngToken:  0xA8D54F6FEeAFaf5C2c546D1D1644aE2f46A2d910
```

### 4. Fund Contract
```javascript
// Approve
await dngToken.approve('V3.1_ADDRESS', ethers.utils.parseEther('10000'));

// Fund
await gameContract.fundContract(ethers.utils.parseEther('10000'));
```

### 5. Update Frontend
**In `config.js`:**
```javascript
GAME_CONTRACTS: {
  testnet: 'V3.1_ADDRESS_HERE',
  mainnet: '0xYOUR_MAINNET_GAME_CONTRACT'
},
```

### 6. Deploy Frontend
```bash
vercel --prod
```
